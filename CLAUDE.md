# Claude Code Project Guidelines

## Attribution & Author Policy
- **STRICT REQUIREMENT**: Never add `Co-Authored-By: Claude`, `Co-Authored-By: Claude Opus`, `noreply@anthropic.com`, or any AI/Anthropic attribution trailers to git commit messages or PR descriptions.
- All commits, branches, and PRs in this repository must attribute sole authorship to the human user / repository committer.
- Do not modify git commit message templates to insert AI attribution.
